ℹ FUENTES DE DATOS
OpenCelliD · Torres de celular
Base de datos abierta y colaborativa con millones de torres de telefonía móvil en todo el mundo. Para Chile (MCC 730) incluye antenas de Entel, Movistar, Claro, WOM y GTD con coordenadas, tipo de red y operador.
Nominatim · Geocodificación
Servicio de geocodificación de OpenStreetMap. Convierte una dirección de texto a coordenadas lat/lon para consultar las torres cercanas.
OpenStreetMap · Mapa base
Mapa colaborativo y gratuito del mundo. Se usa como capa base para visualizar las antenas y la dirección buscada.
Índice de señal · Cálculo propio
El índice se calcula combinando: número de antenas en el radio, diversidad de operadores, presencia de LTE/NR (4G/5G) y distancia mínima a la antena más cercana. No mide potencia de señal real.
nPerf y SUBTEL · Validacion adicional
nPerf se usa como referencia de mediciones colaborativas de usuarios y SUBTEL como contraste oficial de cobertura digital. Complementan el analisis de torres, no reemplazan mediciones en terreno.
