# Cobertura Celular 14115 v3.9

Mapa interactivo de cobertura celular y antenas en Chile. Consulta torres cercanas, compara operadores y verifica la señal disponible en cualquier dirección.

## Funcionalidades

- **Busqueda por direccion** o por ubicacion GPS
- **Mapa interactivo** con Leaflet (click para seleccionar punto)
- **Operadores**: Entel, Movistar, Claro, WOM, GTD y otros
- **Tecnologias**: GSM, UMTS, LTE, 5G NR
- **Filtros** por operador y tecnologia
- **Diagnostico de zona**: metricas de senal y densidad de torres
- **Benchmarks** de velocidad por operador
- **Mapas de cobertura oficial** de cada operador
- **Radio de busqueda ajustable**
- **Responsive**: funciona en desktop y movil
- **APK disponible** para Android

## Uso

Abre `index.html` en cualquier navegador moderno. No requiere servidor ni instalacion.

Para Android, instala el archivo `coberturacelular14115 v3.9.apk`.

## Tecnologias

- HTML5 / CSS3 / JavaScript (vanilla)
- [Leaflet](https://leafletjs.com/) para mapas
- Fuentes: Orbitron, Rajdhani, Share Tech Mono (Google Fonts)
